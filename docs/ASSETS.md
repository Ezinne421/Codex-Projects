# Editorial identity assets

The design uses its own identity and layout. PMI is an inspiration for a
professional editorial tone, not a source of copied branding or proprietary fonts.

- Manrope variable font: Google Fonts, SIL Open Font License. Licence included
  in `public/assets/fonts/Manrope-OFL.txt`.
- Newsreader upright and italic variable fonts: Google Fonts, SIL Open Font
  License. Licence included in `public/assets/fonts/Newsreader-OFL.txt`.
- Construction photograph: Unsplash image
  `https://images.unsplash.com/photo-1504307651254-35680f356dfd`, downloaded at
  a bounded size and quality. Governed by the [Unsplash licence](https://unsplash.com/license).
  It is editorial imagery, not a claim that the depicted project uses this app.

Assets are self-hosted. The standalone HTML embeds fonts and their licence text,
so it does not need a third-party font service or network access for typography.
