All six pages returned HTTP 200 during this review. Their relevant visible text
was inspected for the findings above. Existing further-reading links also point
to APM, ASQ, the Lean Enterprise Institute, ASCM, CIPS, OECD, UN SDGs and Google's
SRE book. A successful HTTP request does not establish the validity of every
claim; the linked organisation is not endorsing this application.

Maintenance: revisit official sources when requirements change and before
updating the snapshot date in `shared/knowledge/learning.ts`. Review edition
names, effective dates, errata, certification requirements and changes affecting
lesson advice. Update affected lessons and practice explanations together. Keep
examples labelled as illustrative, and retain assumptions beside calculations.
Never advance the review date solely because a build or link check passed.
The UI warns when the snapshot exceeds 90 days; it does not run a scheduled
editorial refresh or automatically ingest unreviewed guidance.


## Practitioner glossary expansion — 2 November 2026

The library adds 200 original definitions in eight specialist topics. Each new
entry includes an illustrative example, a practical application and a common
mistake. Fifty existing entries receive the same depth, and 50 explicit concept
comparisons are linked in both directions. Selected advanced metrics include
formulas and conditions, including the restricted M/M/1 queue model and a
hypothetical single-deduction tax gross-up. Neither is presented as a universal
operating or country-specific rule.

Sources are assigned by relevant subtopic: clinical entries point to WHO,
agricultural entries to FAO, humanitarian entries to Sphere, software delivery
metrics to DORA and AI concepts to NIST. Related entries use local subject groups
rather than linking every sector to the first construction terms.

These are source and subject-context checks, not a claim that each original
sentence appears verbatim in the references or that all contracts, jurisdictions
and sector rules have been validated. Formal requirements vary by the actual
country, contract, rights framework and professional context. Keep these
boundaries visible when maintaining entries.
